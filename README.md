## #Limpieza de base de datos world_layoffs

## Contexto inicial

Documentar el proceso de limpieza de datos utilizando el motor de MySQL, paso a paso y patrones reutilizables en contextos similares.
Este proceso consta de 4 pasos: Eliminacion de duplicados, estandarización, modificacion de Null/en blanco y eliminación (en caso de ser necesario)
